# EmptyHands website

A rebuilt, static version of [emptyhands.co.uk](https://emptyhands.co.uk) — the EmptyHands traditional Karate, Tai Chi, Yoga, Shiatsu & Coaching school in Ilford and Epping.

All text, photos, videos and PDFs come from the original site. No framework, no server: plain HTML, one stylesheet and one small script, so it can be hosted anywhere (GitHub Pages, Netlify, any web host).

## View it

Open `index.html` in a browser, or serve the folder:

```sh
cd emptyhands
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Pages

| Page | What's on it |
| --- | --- |
| `index.html` | Video hero, the five disciplines, four pillars, Dojo Kun, timetable, founder, dojo film, testimonials, black belts, journal, locations |
| `karate.html`, `yoga.html`, `tai-chi.html`, `shiatsu.html`, `coaching.html` | Class details, times, fees, grading path, related articles |
| `about.html` | Story, timeline, what we offer, values |
| `instructors.html` | Azeem Sensei, Irm Sensei, Reet Senpai + mentors |
| `yudansha.html` | All 15 black belts with full profiles (click a card) |
| `fees.html` | Tabbed fees for every discipline and grading |
| `testimonials.html`, `gallery.html` | All reviews; photo gallery with lightbox + the full dojo film |
| `contact.html`, `join.html` | Both dojos with maps; contact and trial-class forms (open the visitor's email app or WhatsApp — nothing is stored) |
| `blog/` | All 26 journal articles with category filter and search |

## Editing

Pages are generated by `_build/build.py` (Python 3, standard library only):

```sh
python3 _build/build.py
```

- Timetable, fees, testimonials, black belts, contact details: edit the data near the top of `_build/build.py`, then rebuild.
- Blog posts: `_build/content/posts.json` (originally imported from the WordPress site with `_build/import_wp.py`).
- Styles: `assets/css/style.css`. Behaviour: `assets/js/main.js`.
